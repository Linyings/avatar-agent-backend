# 通用模式：解说与原片承接规则

2026-10-29。

将用户要求补入服务端通用模式写稿系统提示及 `source-and-ownership.md` 适配规则，覆盖完整稿、原片衔接整理和获授权的局部润色。

- 解说铺垫必要背景、困境或待回应的冲突，讲完直接接原片下一句对白或下一步行动。
- 不先用解说讲完一个剧情变化，再播放表达同一信息的原片；也不在原片之后复述刚刚发生的事件。
- 按事件含义去重，改写对白和同义转述也算重复；必要称呼和指代可以保留。
- 原片负责揭晓答案、选择和结果；之后的解说推进有证据的新变化。
- 在原有写稿调用内连读前解说、原片实际内容、后解说并自我修订，不新增调用或导出阻塞。
- 保持用户所选风格、原片标记、锁定范围和局部修改授权；逐字恢复及纯原片流程维持原有行为。

规则内容进入现有提示词指纹，重新请求写稿时使用更新后的规则。已完成的项目不会自动重写，须新建项目或重新执行生成完整解说稿。

此修改强化写作要求，并不保证模型每次都完全遵守，也没有改变画面匹配阶段对原片范围的处理。
