# 正脸讲解人物与面部真实感

适用节点：F06 人物参考图准备、数字人口播素材生成。由后端固定注入，不依赖聊天模型自主读取。

保持参考人物的年龄、原有肤色、脸型、五官比例、发型和识别特征，不美白、不改变年龄，不凭空添加斑点或皱纹。
皮肤呈自然半哑光：鼻翼与邻近脸颊保留细微局部毛孔和受光细绒毛；鼻梁和鼻尖只有克制的局部反光，脸颊、眼下较哑光。避免塑料感、蜡感、过度磨皮、锐化颗粒和均匀油膜。
遵循参考照片的柔和照明，保留自然肤色层次。视频中肤色、毛孔和细微纹理跨帧稳定，五官不漂移，高光随轻微动作连续变化，不闪烁。
人物头部正对镜头，双眼看向摄像机，像面对粉丝亲切讲解；允许自然眨眼、轻微点头和自然表情，避免僵硬瞪眼、转头、侧脸或视线游离。
腰部以上中景，头顶、下巴和双肩完整，人物居中，脸高约画面五分之一，四周保留裁切余量。固定机位、焦距和拍摄距离，整段取景稳定。
侧脸输入先准备身份一致的正脸参考图；所有口播段复用同一张已验收参考图。参考图与视频分别验收朝向、视线、身份和质感；不能用声音相关度代替视觉嘴型验收。
