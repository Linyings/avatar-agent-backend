# 场景切分与编辑设计方法

本文件提供按内容选用的配方。时长、位置、形状和配色都应根据文案、音频、比例与观看环境调整。

## 1. 从台词到场景

先为每段台词写“讲述动作”：提出问题、给出例子、解释关系、演示操作、比较差异、说明条件、归纳结论或要求行动。再为动作选择一个能看懂的主视觉。

| 台词正在做什么 | 优先主视觉 | 保持同场的条件 | 值得切换的条件 |
|---|---|---|---|
| 向观众提问、表态、建立交流 | 人物全屏或人物主导 | 仍在直接交流 | 开始需要图解证据 |
| 解释输入到输出 | 输入卡、处理过程、结果 | 关系骨架不变 | 换成完全不同的问题或案例 |
| 逐步说明一个流程 | 完整或渐建的路径、当前步骤 | 后续步骤仍属于同一流程 | 进入另一流程或需要局部放大解释 |
| 对比两个方案 | 并列或上下对应的对象 | 比较维度和对象不变 | 转入真实案例或复杂数据表 |
| 举例或打比方 | 场景插画、界面、具体物件 | 例子仍服务同一论点 | 回到概括或换论点 |
| 解释数据与条件 | 图表、数字、标签 | 仍能在同一图中读懂 | 密度过高需拆页或换展示方式 |
| 强调结论或优先级 | 已有对象重排、高亮、总结 | 结论可由已有图形推导 | 进入新的章节目标 |
| 引导操作 | 按钮、光标、结果状态或人物 | 操作属于同一任务 | 操作完成并进入收尾 |

对每个边界写“切分理由”。“已经讲了五秒”不是充分理由；“从说明三个输入转为比较两种执行方式”是。

## 2. 两种讲解模式

### A. 人物与图解交替

适合交流、演示、例子和资料交替出现的内容。

常用状态：

| 状态 | 作用 | 设计重点 |
|---|---|---|
| 人物全屏 | 开场、直接提问、表情手势、转折、结尾 | 留出头部与动作空间；文字避开脸和手 |
| 内容主导＋人物小窗 | 讲解图表、界面、故事 | 主内容占可读空间，窗口位置避让当前焦点 |
| 内容独占 | 密集表格、操作细节、重要证据 | 暂时隐藏人物，保留正确人声与源时间 |

一条可选路径是“全屏交流→小窗图解→内容独占→全屏转折→小窗继续”。只有内容需要时才走这条路径，不强制凑齐状态，也不按时钟循环。

### B. 固定面板持续讲解

适合连续推理、路径设计、清单和知识讲解。

开场后建立稳定的背景、信息面板、人物窗口和字幕区。内容在面板内更换，人物持续陪讲。通过骨架保留、节点点亮、方向变化和卡片位置变化表达进展。

需要交流时仍可临时回全屏，面板太拥挤也可隐藏人物。固定的是观众寻找信息的习惯，不是禁止必要的布局调整。

### 比例适配

- 横版容易容纳横向对比、宽表与旁侧人物；不要因此把信息无限摊开。
- 竖版常用纵向流程、上下对比或分步分页；把小字宽表原样缩小通常不可读。
- 以实际发布平台的界面遮挡和目标观看尺寸设安全区。人物、字幕、重要数字不得互相遮挡。
- 圆窗偏重头肩与表情；圆角矩形更容易保留手势。根据表达任务选择形状。
- 布局坐标可用 0～1 的归一化值描述，但圆形判断仍按输出像素计算：矩形的像素宽高相等才是圆的外接正方形。不能直接要求归一化宽高相同。

## 3. 图层职责

| 图层职责 | 可放内容 | 何时更新 |
|---|---|---|
| 背景 | 纯色、纸感、暗化模糊房间、场景图 | 风格或叙事空间改变 |
| 信息容器 | 面板、卡片外框、表格结构 | 布局改变；普通换内容可保留 |
| 主要解释对象 | 卡片、界面、图表、角色、路径 | 新场景或新步骤 |
| 注意力标记 | 箭头、框选、进度、数字、勾选 | 对齐台词的事件点 |
| 人物 | 干净人物源片的全屏或小窗 | 布局状态改变；源播放连续 |
| 字幕与导航 | 字幕、章节名、进度、必要身份信息 | 随台词或章节更新 |
| 特效覆盖 | 遮挡转场、短强调、片尾效果 | 有明确理由的短区间 |

这是视觉职责划分，不强制某个渲染器使用七条轨道。每个镜头写清遮挡顺序；字幕与人物应有独立安全区，不能只靠提高图层顺序补救。

## 4. 用动效表达关系

| 要表达的关系 | 场内事件序列 | 验收重点 |
|---|---|---|
| 递进流程 | 建立骨架→点亮当前节点→保留完成状态→展示终点 | 观众能找到当前步骤，也能回顾前后关系 |
| 串行与并行 | 两组同量任务→依次执行与同时执行→对照完成状态 | 比较尺度一致；示意时间不能冒充实测性能 |
| 倒推与正向展示 | 先放目标→反向连接条件；再用相反方向解释呈现顺序 | 箭头的起终点和方向与台词一致 |
| 优先级调整 | 两卡保持身份→交换位置→重要卡提亮，次要卡弱化 | 位置变化本身能说明重点为何变化 |
| 条件与结果 | 条件逐个满足→连线或状态更新→结果可见 | 不让结果在条件之前无解释地出现 |
| 输入组合 | 输入对象依次出现→关系连接→输出对象出现 | 能看清每个输入及其作用 |
| 操作反馈 | 指针接近→点击→局部反馈→状态变更 | 点击与结果有可辨的先后关系 |
| 结论强调 | 暂停新信息→强调关键对象或短句→稳定停留 | 给理解留时间，不用特效遮挡结论 |

不同颜色要有稳定职责，例如普通、当前、完成、警示。可同时配合形状、标签或位置，避免只凭颜色区分信息。

## 5. 转场选用

| 类型 | 使用理由 | 通常保留什么 | 注意点 |
|---|---|---|---|
| 直接切换 | 明确的新对象或证据，切后立即可理解 | 必要人声与字幕连续 | 避免切断有用动作和未读完的信息 |
| 内容区替换 | 同一讲解模式中的新场景 | 背景、人物、字幕、容器 | 控制旧内容退场与新内容进场，避免无意空等 |
| 人物收窗／展窗 | 人物与图解之间转移注意力 | 人物当前源时间、人声 | 改容器与取景，不拉伸人像；过渡后稳定 |
| 遮挡揭示／章节页 | 叙事阶段明显改变 | 必要导航与音频连续 | 在遮挡时替换内容，不把每个小点都做成章节 |
| 短暂强调 | 重要结论需要突出 | 原场景结构 | 这是事件，未必是新场景；效果后及时恢复清晰 |
| 整体片尾效果 | 内容结束，进入品牌或结束页 | 结束所需的少量元素 | 整画面关屏挤压不能变成常规人物缩放规则 |

从参考测得的某次转场时长只用于理解节奏，不作为全片统一硬值。先按台词和动作设计，再在实际帧率下细调。

## 6. 素材与提示词分工

| 对象 | 提示词或制作指令应描述 | 交给合成环节 |
|---|---|---|
| 人物源片 | 人物一致性、普通矩形画面、机位、景别、完整头肩或手势、自然口播 | 圆窗/圆角、最终尺寸与位置、描边、字幕、窗口收放 |
| 插画或场景图 | 主体、关系、风格、构图及需要留出的空间 | 时间轴、显隐、框选、切换 |
| 图解动效 | 对象、初始状态、触发点、属性变化、终态 | 按工具能力决定在场景动画内部还是最终合成执行，避免重复叠加 |
| 字幕与身份文字 | 准确文本、层级、换行和位置 | 排版、描边、进出及安全区检查 |

可编辑文字、表格和数据优先作为独立排版对象，便于校对与修改。背景是否透明、是否含人物或字幕应在素材约定里明确，以免合成时重复出现。
