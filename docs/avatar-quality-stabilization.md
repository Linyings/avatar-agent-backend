# 人物稳定裁切与正脸生成

## 2026-11-10 实现

- 渲染使用 `stable-crop/1`：每个连续镜头固定缩放，稳健中位数定位，孤立异常检测剔除。人脸在中央安全区内时固定裁切，接近边缘才以限速、限加速度平移。检测缺失保持位置，素材切点独立规划。所有坐标预先计算，支持 Remotion 乱序并行取帧。
- `render-quality.json` 记录实际 crop policy、每段固定 scale、平移幅度。保留历史 framing 字段用于近景裁切提示，不把它当作实际变换参数。
- 新 Kling 运行固定保存 `config_snapshot.portrait_policy`，包含完整 `portrait-realism` 技能、哈希、策略版本、图生图模型。旧运行继续原有参考图链路。生成策略与照片元数据参与人物素材缓存；正脸参考图缓存按照片实际字节、技能和模型区分。
- F06 固定注入技能；自由分镜文本中的脸部朝向、视线、景别、画幅与运镜由结构化固定要求覆盖，兼容的服装、环境要求保留。
- 先用已有视觉服务检查上传图。合格图直接复用；可辨认但朝向、视线或取景不合格时，用 `seedream-v4.7/image-to-image` 准备正脸图，再与原图进行身份、朝向、视线、质感和取景检查。可通过服务端 `AVATAR_PORTRAIT_MODEL` 指定注册表里的图生图模型。该默认是待实测候选，不是效果已认证模型。
- 一个项目相同输入复用已验收参考图；每条人物视频抽取 8 帧，与参考图一起检查。unknown 不算通过。未通过时保留原付费订单，不自动付费重生。采样验收不能保证所有帧，也不测视觉嘴型同步。
- 参考图图生图订单沿用持久化提交、查单机制；提交不确定时禁止重交。F06 显式整节点重做可产生新参考图版本。

## 验证与付费小样

本地回归：`backend/scripts/test-avatar-quality.sh`（WSL Docker，CGO，无测试 overlay）；runtime Node tests 与 Python unittest。

已有素材重渲染只消耗本地算力。新生成小样建议：Seedream 4.7 图生图最多 1 单 + Kling Avatar Pro 约 5 秒 1 单，并使用已配置视觉服务做输入、参考图和视频采样检查。费用单位以供应商返回为准，不预设人民币。小样效果通过后再重做完整人物素材。

当前头像若只有侧脸，被遮挡一侧需要模型补全；身份检查不能代替用户辨认。语音相关度只验证驱动音频保留，不等于视觉口型评分。
