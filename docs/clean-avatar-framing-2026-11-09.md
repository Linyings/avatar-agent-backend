# 干净口播素材与后期人物窗口

用户已确认实施原方案第 1、2 项：人物模型输出普通矩形口播；窗口形状和裁剪由后期工具完成。

## 具体修复

人物生成原先直接拼入 need.prompt，导演稿中的圆窗、分屏、推近要求因此可能进入视频模型。现在从发给模型的补充描述中过滤这些后期及运镜要求，保留原始提示词用于审计；明确普通矩形全画幅、单主体、完整头顶和肩部、固定机位与焦距、稳定人物大小、原配音时间不变。台词原文不参与过滤。导演规划、素材规划和 AI 提示词改写也遵循这一分工。

原人物检测逐段执行后，用最后一个子片段的人脸框覆盖整段素材，并按最高检测置信度选脸，容易选到背景小人像。现在在拼接后的完整素材上按时间采样，优先选择面积最大的主人物；先对同一张脸的重叠检测框去重，再把大小相近的多个不同人物标为不确定。报告保存真实采样时刻、脸框、片段边界、检测率及源片构图变化，缓存与实际文件和检测版本绑定。

后期使用源入点加镜头内时间查询相应脸框。窗口位置、大小和形状固定，为整镜选择一致的脸部显示高度，再按检测数据等比例缩放、平移，不添加推近动画，不分别拉伸宽高。圆形取景保留头顶、眼、嘴和下巴余量；圆角矩形及普通矩形使用同一定位逻辑。整镜检查还要求素材能填满窗口，避免圆窗里出现一条窄视频和大片留白。定位不足或源片特写过近、无法同时填满窗口并保留头部时，整个镜头保留完整矩形画面；实际形状、取景模式及降级提示写入 render-quality.json 和逐镜检查报告，不会中途切换窗口形状。渲染版本升级为 film-design/3，仅本地构图缓存失效。

## 范围与限制

- 不自动重生人物、不修改原成片、不重跑配音。原始有缺陷素材继续可追溯。
- 已经烘焙进源片的重复文字、人像以及缺失的身体部分，后期不能可靠恢复；报告会提示复核，必要时用户明确发起人物节点重做。
- 人脸检测不是身份识别或口型评分。严重遮挡、多主体和明显切镜可能需要人工检查。
- 这次没有增加生成模型单次输出体积；检测、裁剪及验证均在本地执行。
