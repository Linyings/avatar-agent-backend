# 内容驱动的画面编排

> 动效部分已被后续用户要求取代：当前使用 [mg-native/3 全15套原版模板](mg-original-styles.md)。本文中“五套风格”“内容图解”“示意人物缩略图”是上一轮实现记录，不再描述当前的 F07 与风格选择页。

本轮版本：`film-design/1`，继续使用固定 Workflow。没有增加数字人角度、通用 Agent、额外模型或自动付费重生成。

## 行为变化

- 五套 MG 风格的背景、文字、强调色、信息面板、人物容器和字幕统一取自 `filmTheme`。
- 增加八种可渲染镜头配方：人物主讲、人物与侧边信息、素材主画面、素材与人物小窗、对比、步骤、数据证据、总结。
- F05 仍只列需求；F07 使用按原稿内容驱动的可信组件生成动画。原始 MG 源码、案例、提示词和演示影片保留，和内容模板明确区分。
- F09 完成真实音轨及素材核对后，F10 内先运行本地语义候选分析及 talkcraft 卡片匹配，再将候选、素材几何与安全区交给已有文本模型。没有增加一次独立模型调用。108 张原库卡片仅作参考，不宣称均已实现。
- 去掉每镜固定底部白卡。动画拥有自身标题和图形时，不重复叠信息卡；人物默认单机位，可通过构图变化切换主次。
- 人物按实测头部安全区决定是否安全裁切，否则保留完整画面并延展背景。字幕使用独立安全区，英文单词保持完整，停顿时不跳回首句。
- 相同配方连续出现仅提醒，不强制切镜、不阻塞、不自动重生成。真实素材缺失或时间区间无效仍按必要产物错误处理。

## 页面

风格动态缩略图改为带有“示意人物”的整片构图演示；原片、原提示词和源码包仍可单独查看。任务区域增加镜头设计列表，局部分镜编辑可选择配方及信息卡。素材编辑支持数据模板。

已有完成视频不会被覆盖。新任务使用新设计流程；从已有项目创建新版本可以复用有效配音和人物素材。历史订单保留供应商配置和原输入哈希，纯本地渲染版本变化不会被误判为更换供应商；供应商或模型配置变化仍拒绝查错订单。

## 验证与证据

- Go：内容候选、八种配方、原文摘录、源时间约束、重复构图提醒、历史供应商配置兼容与现有 Workflow 回归。
- 渲染：三比例几何、安全区、字幕分组和来源校验；Python 验证分镜前分析及内容图解；前端验证风格与历史任务交互。
- `deploy/wsl2/review-film-design.sh` 复制已有真实素材到独立评审目录，重新生成本地动画、24 张配方检查帧及完整 MP4。它不提交任何模型请求，不覆盖历史任务。
- 离线对比使用确定性评审分镜，只能验证排版、合成和音轨连续性，不替代真实模型新一轮分镜效果或嘴型验收。

实现参考 `video-talkcraft/references/shot-design.md`、`design-language.md`、`cinematography.md`，以及 `mg-styles-15` 原始风格。应用组件是适配实现，原参考目录未修改。
