## 2. 分层融合与动效

从成片可以辨认出以下合成结构。实际工程可能使用不同组件拆法，但视觉职责一致：

1. 背景层：米白纸感底、细颗粒与少量装饰点；夜景和章节页替换为深色或荧光绿。
2. 主内容层：聊天窗口、文档、波形、表格、进度队列、费用牌等，每场只有一个明确的信息中心。
3. 辅助解释层：箭头、框选、关键词、数字、状态标记，回答“此刻该看哪里”。
4. 贴纸角色层：卡通小人、电脑、杯子、床、钱包等，承担比喻、动作和情绪。
5. 数字人视频层：全屏/小窗/退场，由后期布局控制。画面可见其原房间背景，不是抠成透明人物再放到纸面上。
6. 字幕和章节进度层：保持在底部，不跟着人物窗口一起缩放。全屏人物时改变对比以保证可读性。
7. 转场遮罩层：在需要换章节或覆盖旧内容时启用。

这种风格的统一来自重复的视觉规则：米白、黑、荧光黄绿为主，少量橙黄点缀；卡片、图标和人物贴纸常带描边、浅阴影、轻微倾斜。主物件、配角和小标记共同形成画面，单纯放一个大标题不能复现这种信息密度。

可以复现的动作包括：位移与透明度控制进出场；小幅旋转制造贴纸感；条形的长度或裁切比例控制进度；文字按时间逐字显现；箭头路径逐步绘出；数值按进度更新；高亮框在被讲述的对象周围出现。PNG/SVG 能做静态图形，代码负责这些属性随时间变化。仅凭成片不能确定某张贴纸原来是手绘、SVG 还是生图。

02:27–02:37 的队列是很好的例子：两行格子、执行者、计数器都是独立对象，逐次更改状态即可表达串行与并行，不需要每完成一格就重新生成视频。

## 3. 数字人镜头组合

人物有三种主要展示状态：

| 状态 | 本片用途 | 后期控制 |
|---|---|---|
| 全屏 | 开场、证明动作效果、提问、转折、收尾 | 保留正面中景和手势空间；标签放在脸与手之外。 |
| 右下小窗 | 介绍图形内容、说明流程 | 稳定的圆角近方形窗口，宽约全画面 1/5、高约 1/3，避开底部字幕和章节条。 |
| 隐藏 | 约 02:37–03:10 的密集表格 | 保留讲述的时间连续性，把画面空间交给图表；回来时先全屏交流，再缩小进入下一段。 |

这里使用最多的是圆角方窗，不是圆形头像。它留出了更多头肩和手部空间。窗口内部能看到原人物房间背景，因此基础方案是对普通矩形视频等比缩放与裁剪，再加圆角遮罩。

全屏变小窗时，在约 0.3～0.5 秒的过渡里，窗口位置、宽高、裁切范围和圆角一起变化。过渡结束后小窗保持稳定，不能把“整个窗口进出”与“镜头内持续放大人脸”混为一件事。

作者当前公开文档确认了共同的底层机制：全屏与小窗使用同一人物视频与同一时间基准；人物视频本身静音，人声单独播放；缩放保持宽高比例；后期运镜与视频模型的生成职责分开。该机制与实际观察到的窗口变化一致，但不能据此确定这条片子的每项参数。

可行的工程实现是先生成固定机位人物素材，再用一个布局控制器记录「何时全屏、何时小窗、何时隐藏」。在成片时间 t 处，无论窗口多大，都读取对应人物源时间；镜头中若用了截取片段，则按明确的源入点映射。窗口切换不应让人物视频从头播放。

此外，大量小切换只发生在主内容区：旧物件淡去或离开，新物件再进入，纸面、人物小窗、字幕与章节条保持。比如声音波形切到磁带、文档切到聊天界面、发送按钮切到进度条。保持这些连续元素，能让多个场景看起来属于同一段讲解。

作者文档提供按词级时间戳触发事件的机制。复现时可以让“说到输入材料”触发卡片出现，“说到三份同时执行”触发三格同步运行，“说到看我的手”触发全屏人物。事件点来自台词时间，物件需要的入场、停留和退场时间再围绕这个点设计。

## 对当前项目的具体启发

- 规划时单独描述人物状态：全屏、小窗、隐藏。不要让人物每隔固定秒数机械放大缩小。
- 将一段口播中的画面任务写明确：展示本人、解释流程、演示数量关系、提出问题、总结引导。画面任务决定人物是否需要占主要位置。
- 人物素材与合成镜头分开管理，同一人物素材可以在多个镜头和多个窗口状态中复用。字幕与章节条也独立管理。
- 每个动效场景包含一个主要解释物和少量相关配角；关键词、箭头、进度等按照台词逐项出现。
- F10 的组装方案应输出主视觉、人物状态、源入点、内容事件时间和过渡方式；后期渲染按这些字段真实合成。镜头划分无需等同于人物生成任务划分。
- 圆角方窗适合保留头肩与手势；圆窗可作为另一种选择，但不能默认所有场景都用圆窗。源素材取景、字幕安全区和图表布局应一起检查。
