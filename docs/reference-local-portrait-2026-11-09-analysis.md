## 3. 分层结构与视觉风格

按可见职责，可以拆为以下七层；这是复现用结构，不是作者工程的确认清单。

1. **氛围背景**：铺满竖屏的模糊房间与人物轮廓，整体压暗。视觉上与开头房间一致；复现可复用人物素材的模糊副本，也可用独立房间背景。
2. **讲解面板**：深灰、半透明的圆角面板，带细边线和紫色柔光，放在画面中上部。
3. **讲解内容**：文章卡、帖子、流程节点、对比卡、图标。大部分动态发生在这一层。
4. **强调元素**：紫色箭头、黄绿色亮点、勾选、删除线、关键词和总结文字，明确当前应看的对象。
5. **人物视频**：开头全屏，之后圆窗；圆窗内仍能看到头发、耳机及部分房间，没有必须做透明人像抠图的证据。
6. **字幕与界面身份**：左下黑色字幕框、紫色侧线、人物名牌、顶部 LIVE 与 SCREEN SHARE 文字、章节标题。它们是模拟直播的视觉语法，不能证明真实直播或真实录屏。
7. **全画面特效**：短促故障闪动、片尾关屏；仅在强调或结束处启用。

配色主要是深灰底、淡紫主体和白字，黄绿色用于当前步骤、正确状态与结论。开场背景中的紫色灯光、发色、人物窗描边、图标与品牌色呼应，使视频素材和图形属于同一视觉体系。

卡片入场、文字显现、节点点亮、线条增长、灰显与高亮、两卡交换位置、点击波纹，均可用普通二维图层属性完成；不需要为每个小事件生成一段新视频。

## 4. 人物与动效如何组合

人物的主要状态只有“全屏”和“圆窗”。约 5 秒以后，直到片尾关屏，主体讲解中没有反复返回全屏的大幅人物切镜。小窗约占画面宽度的三成，取头肩与耳机，位于内容面板下方靠右；字幕框放在左侧，而不是一条横贯底部的大字幕。

圆窗内部保留源画面背景，比较适合用普通人物视频等比缩放、确定取景位置，再做圆形遮罩。正常讲解区间人物窗口没有持续推近到大脸的趋势，姿态变化主要来自说话表情和动作。画面仍有轻微位置变化，不能理解为每帧像素完全固定。

制作上可以维持一个独立人物时间轴，与讲解图层共享最终时间。无论全屏、缩窗还是换图卡，都读取同一时刻对应的人物帧；如源视频分段生成，则通过每段的源入点正确映射。导出的成片不足以判断它原来生成了几段，也不能仅凭外观确认具体数字人模型。

人物的作用是保持讲述者在场，动效负责把内容关系画出来。长流程段不靠放大人脸制造节奏，而是让高亮点从一个节点走向下一个节点。

## 5. 可复现的制作顺序

1. 先取得口播音频与分句时间，再准备固定机位、完整头肩的干净矩形人物视频。
2. 将台词划为上表的讲解单元，并明确每场要说明的关系：对比、递进、倒推、列举或行动引导。
3. 建立统一竖屏外框：暗化模糊背景、中上信息面板、右下人物窗、左下字幕框。
4. 每场单独设计内容对象与事件时间，例如流程骨架先出现、对应文字随后显示、当前节点点亮、最后目标卡出现。
5. 用后期合成控制人物的取景和圆形遮罩，开场做一次收窗；字幕及名牌保持独立，不随人物画面一起缩小。
6. 普通场景只切面板内容，在结论处使用一次短强调，最后做整体关屏和品牌页。

在当前项目里，可对应为：素材节点产出口播原片和动效内容；镜头组装方案描述人物状态、构图、取景、时间映射和图层事件；分层渲染执行真实裁剪、遮罩、叠加与转场。一个讲解场景内可以有多个事件，无需把每次打勾、箭头出现都拆成单独模型任务。
