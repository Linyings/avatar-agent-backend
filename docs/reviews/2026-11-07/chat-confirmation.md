## 交互

- 需要审核时，仅在 Agent 对话内显示一张确认卡片。点击“查看文案”或“查看并试听配音”，展开本版本的所有段落与音频，然后点击“已确认，继续”。
- “取消”关闭本次确认，任务继续等待，不会批准、不执行下一步；可以重新查看。刷新后仍由服务端的审核状态决定是否显示卡片。
- 确认按钮绑定运行 ID、审核种类和版本。版本变化后原预览失效；断线、内容不全或版本缺失时不能提交。
- 在待审核或订单待核对状态发送“已确认”，界面只引导用户查看相应卡片，不调用 Agent 或批准接口。
- 移除顶部占据布局的大状态栏和重复开始/恢复按钮；顶部只保留跳转到对话状态卡片的入口。暂停、停止、恢复等操作也集中在对话区。
- 操作失败使用 Mantine Portal 内的固定浮层通知，置于页面上层，可关闭，不改变画布和对话框的位置。
- `submission_unknown` 显示订单核对说明和“刷新订单状态”。刷新只读取服务端已记录状态，不重新提交生成；不再显示会被后端拒绝的“恢复运行”按钮。
