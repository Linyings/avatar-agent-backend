# 工作流运行节点高亮优化

## 实现

- 运行节点使用亮金色标题、外圈、缓慢呼吸光晕和「正在执行」角标。
- 外圈根据画布缩放补偿粗细，选中其他节点不影响运行提示。
- 画布右上角显示正在执行的步骤名称，点击可定位；入边和小地图使用相同颜色。
- 尊重系统减少动画设置；暂停、失败、待确认和完成后移除运行提示。
- 修正素材汇总节点的运行判断：子视频制作期间等待，只有 F09/F10 实际执行时才显示运行中。
