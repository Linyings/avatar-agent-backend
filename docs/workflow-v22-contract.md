# Workflow V2.2：节点与运行契约

需求基线：PRD V1.10。实现版本：`avatar-workflow/2.2`。固定工作流，不接受模型输出的后继节点、可执行代码或额外付费调用。

## 固定节点

| 节点 | 必需输入 | 输出与推进条件 |
| --- | --- | --- |
| F01 | 照片、主题/稿件、风格、音色、可选源素材、比例 | 项目草稿 revision；上传文件由服务端探测、计算 SHA256 |
| F01.4（可选） | 未排除的本地视频 | 每 20 秒一批、每秒抽帧的视觉理解；源时间、片段文案、抽样范围；全部批次完成后才写稿 |
| F02 | 主题、可选原稿、理解结果 | 可确认的最终解说稿；现成稿默认保留，提醒核对素材事实 |
| F03 | 最终稿 | 按内容拆段，连续原文按序覆盖一次；不分配画面；确认版本绑定实际内容 |
| F04 | 已确认段落、实际音色 | 独立 WAV、CPU 实测字词时间戳、实测时长；用户试听确认后才进入 F05 |
| F05 | 确认声音、时长、稿件、风格及制作要求 | 人物、动画、真实素材需求；不生成、不搜索、不组合、不剪辑 |
| F06 | 人物照片、对应分段声音、明确角度及提示词 | 默认单角度上半身人物视频；长段按真实字词间隙拆成供应商允许的子订单 |
| F07 | 动画内容、模板、实测时间与字词事件 | 参数化动画 MP4、原提示词及本次适配参数 |
| F08 | 本地真实素材及源片段文案 | 静音提取的真实源区间；保留“解说段—片段文案—源入出点”关联 |
| F09 | 全部必需素材、声音与时间戳 | talkcraft 全局时间基、完整旁白、同源素材清单 |
| F10 | 已就绪素材及时间基 | 语义标注、SHOTBOOK、同源 JSON/TS 镜头表、源入点、组合意图 |
| F11 | 可消费镜头与组件 | Remotion 实际有声分镜预览；尚无真实输出不报成功 |
| F12 | 同一版本的工程及有效镜头缓存 | MP4、SRT、封面、工程 ZIP、映射、成本耗时报告；人工效果审片另记 |

## 状态与错误

- 执行状态：running、awaiting_confirmation、stopping、stopped、failed、interrupted、submission_unknown、succeeded。
- 只有稿件和声音有内容确认点。质量事件另存 events，不写入计费用量，不改变运行状态。弹窗关闭/不处理都不停止制作。
- 可播放视频的声音包络低相关、疑似嘴型/画面瑕疵、检查脚本失败只提醒。包络相关度不是嘴型评分。
- 缺少必需音频、无法解码、源区间不够、时间轴有洞属于技术错误。其他独立素材继续执行，依赖缺失产物的后期等待恢复。
- 模型返回不支持的可选组件或布局，使用现有保守组件并提醒；不再调用模型。缺少真正可消费的素材/时间映射不会假报成功。
- 用户停止与提交共享事务锁；持久化 submitting 是提交进入在途状态的裁决点。停止后不再准入后续提交，不假称取消/退款已在途订单。
- 确认绑定待确认内容摘要，运行请求绑定 revision 与幂等 ID；过期确认返回冲突。

## 订单、恢复与计量

- 外部提交前持久化状态；取得供应商 taskId 后立即保存。超时继续查询原单。无 taskId 且 submitting/unknown 时禁止盲目重交。
- 成功文件可复用；下载失败只查/下载原单，不重新生成。供应商明确终态失败后，手动重试保留历史订单。
- 服务重启不自动重发；租约过期标记 interrupted，由恢复入口查原单。当前租约 90 秒，服务端每 20 秒续期。
- 每节点保存尝试、开始/结束、耗时、状态、原订单、供应商 usage；底层 HTTP 操作另记 operations.jsonl。中断耗时为开始至检测中断的墙钟时间，包含故障等待，不宣称纯模型计算时间。
- billing 按供应商 taskId 去重；同一订单反复查询不累加。LLM 按实际尝试记录。未知费用不是零；未声明币种的字段保留原值，不当作人民币。
- 历史版本不转换、不重交订单、不改写成本。真实验证中的排错调用与目录预生成用量单独记录。

## 数据与安全边界

- 继续使用 Project、WorkflowRun、WorkflowStepExecution。项目元数据保存 avatar_v2 输入；运行冻结输入与非敏感配置摘要。每个节点另有 v2. 步骤记录。
- 状态和提醒保存在数据库；大文件位于 `/app/data/avatar-mvp/workflow-v2/`。项目 cache 与运行目录分开，素材缓存同时保存人脸安全区元数据。
- 所有项目、运行、原素材及产物接口检查所有权。媒体使用鉴权 Blob，支持 Range，不使用 URL JWT。
- 通用项目元数据接口不能注入或覆盖 V2 管理的媒体路径；专用上传接口负责验证格式、大小、探测和路径。
- 模型密钥只在 WSL 服务端 .env。运行快照、报告与工程不含密钥；浏览器不调用供应商。

## 局部修改依赖

| 修改 | 复用 | 失效范围 |
| --- | --- | --- |
| 字幕颜色、字号、同字数更正、人物小窗位置 | 声音、人物、动画、理解结果 | 相关镜头和成片；字幕更正沿用原实测字时，不修改朗读 |
| 一段稿件/配音 | 未变段落的声音及素材 | 本段声音、必要素材、后续全局时间与受影响镜头 |
| 风格/动画模板 | 声音、人物、视频理解 | 动画及后期渲染 |
| 比例 | 声音、人物原片、理解结果 | 比例相关动画及合成 |
| 人物照片/人物要求 | 未变声音、理解结果 | 必要人物素材及镜头 |
| 源片段文案修正 | 原理解证据、已确认稿件与声音 | 素材匹配及后期；重新明确确认，不静默重写稿件 |

## 接口

统一前缀 `/api/v1/avatar-mvp`：catalog（含风格预览/静帧、音色试听）、projects CRUD/assets/runs、runs 查询/confirm/retry/stop/events 已读/artifacts。旧 tasks 查询及视频入口继续保留。

## 已知效果验收边界

图片＋参考声音是供应商输入能力，不代表已经保证身份、原音色或嘴型同步。人工评价与制作成功分开。只验证一个视频模型服务商也不能宣称其他适配已完成真实验收。抽帧理解会遗漏采样间的短暂动作，报告须保留这一限制。
